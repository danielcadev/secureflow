# M0.3 milestone status and claim boundary

Status: local release preparation in progress; no `v0.3.0` tag or release exists.

| Workstream | Current evidence boundary | Gate before publication |
| --- | --- | --- |
| Release provenance | Deterministic source-archive tooling, a distinct host-specific Linux bundle, checksums, workflow attestations, and release-note presentation checks are implemented locally. | Run the full release path from the exact final commit, review every retained artifact, and obtain explicit publication approval. |
| Secure Engine | Candidate precision and fixture-policy work is developed in its own repository and is not established by this metadata branch. | Merge the approved Engine change, wait for green `main` CI, pin the exact Engine identity, and preserve its regression results. |
| npm CLI pilot | A fresh analysis with the candidate Engine is pending integration. | Rerun the pinned target revision, account for every finding and abstention, and record tool identity, target identity, limits, timing, and resource use. |
| Mitiquete Web/API pilot | Only offline source inventory is in scope at this stage; routes and candidates are not vulnerability findings. | Integrate the offline evidence, preserve target identity and authorization, and keep any later network validation passive, rate-limited, redacted, and separately approved. |
| Human comparison | The prospective protocol exists, but participant execution and independent blinded adjudication have not started. | Preregister the study, run equivalent-capability cohorts on an unseen holdout, publish uncertainty plus negative and mixed results, and avoid general superiority claims. |
| Knowledge base | The 50,000/100,000-record workstream is a synthetic capacity, deduplication, integrity, and latency gate. | Integrate reproducible evidence and distinguish source records, canonical records, aliases, reviews, and human-validated vulnerabilities in every reported count. |

The allowed M0.3 claim is narrow: SecureFlow is preparing a reproducible, local-first workflow and measuring specific components under recorded conditions. This milestone does not establish global vulnerability coverage, production safety, autonomous validation, a database containing 50,000 or 100,000 validated vulnerabilities, or performance superior to human researchers.

`CITATION.cff` intentionally remains at published version `0.2.0` with its existing release date. A finalization change may update it only after the exact `v0.3.0` contents, tag target, and publication text are approved.
