## Verification and artifacts

The tag workflow builds a deterministic source archive and a separate host-specific Linux bundle using pinned Rust 1.92.0, each with an adjacent SHA-256 checksum and GitHub artifact attestation. The Linux bundle includes source, schemas, documentation, CycloneDX SBOM, dependency-license declarations, build provenance, and internal checksums. Publication verifies the exact tag, commit, build run and attempt, retained artifact ID and digest, archive checksums, attestations, and staged release uploads.

A supplementary `codesupply-ready-0.4.0-rc.2.json` receipt and adjacent checksum record the exact merged commit, local validation, CodeSupply demo evidence, and published archive identities. This operator-generated receipt is separate from the two GitHub-attested archives. Only completed gates are recorded as passing.

## Limits and authority

SecureFlow remains local-first and requires explicit authorization for target analysis. Only a human reviewer may validate a vulnerability; this synthetic walkthrough makes no claim about real-world vulnerability detection, production safety, performance against human researchers, or complete security coverage. No remote reconnaissance, exploitation, provider transmission, or invented human verdict is part of the demo.

Source archive byte equality is checked for the compared builds. The Linux bundle is host-specific and does not claim cross-host binary reproducibility. Checksums and workflow attestations establish artifact integrity and provenance, not that the code or its dependencies are free of vulnerabilities. The release tag itself may be unsigned.
