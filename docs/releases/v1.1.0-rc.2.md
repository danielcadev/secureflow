# SecureFlow v1.1.0-rc.2

<!-- secureflow-release-state: draft -->

This local release candidate gives the Unified Review Room a distinct plugin and CLI identity after the `rc.1` skill had already been cached by active Codex tasks. It is an evaluation candidate, not a stable or production-readiness claim.

## Change from rc.1

- The launcher accepts repeated exact `--case` paths, validates them before startup, and creates an ephemeral tokenized session bound to loopback.
- Codex opens the session-bearing URL in its right-side browser panel and Review Room loads the component set immediately, without a file-picker step.
- Manual file selection remains available when no cases are supplied.
- Chrome, Computer Use, browser-extension file permissions, final human decisions, and remediation authorization remain outside the automatic load.

The session ends with Review Room and exposes only the explicitly supplied case files. Candidates remain unconfirmed until a named person records a final decision through the SecureFlow CLI.
