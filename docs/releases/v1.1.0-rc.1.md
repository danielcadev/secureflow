# SecureFlow v1.1.0-rc.1

<!-- secureflow-release-state: draft -->

This local release candidate adds Unified Review Room and the explicit remediation handoff boundary. It is an evaluation candidate, not a stable or production-readiness claim.

## Highlights

- Review Room loads multiple exact component Security Cases and distinguishes browser drafts from final CLI-recorded human decisions.
- Manual and WebMCP-assisted investigation share one evidence view without giving WebMCP final decision or code-edit authority.
- A human can select validated candidates, constrain allowed paths, and export a local remediation draft.
- `secureflow remediation-authorize` binds the draft to exact case hashes, target identities, revisions, validated decisions, and a named reviewer.
- Remediation handoffs cannot authorize merge or deployment.
- The bundled skill routes an authorized handoff through bounded fixing, tests, and re-scan evidence while preserving the user's merge authority.

## Limits

The browser does not persist final Security Case decisions or authorize code changes. SecureFlow does not patch, merge, deploy, publish, crawl, exploit, or contact a target. Component cases do not establish complete repository coverage, and an authorized patch still requires human diff review.
